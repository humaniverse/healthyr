# Consultant-led Referral to Treatment (RTT) by Scottish Health Board

A dataset containing RTT data for Scottish Health Boards.

## Usage

``` r
scotland_rtt_hb
```

## Format

A data frame with 2,370 rows and 7 variables:

- hb19_code:

  Scottish Health Board code

- date:

  Date

- year:

  Year

- month:

  Month

- specialty:

  Specialty

- waits_over_18_weeks_count:

  Total number waiting \> 18 weeks

- waits_over_18_weeks_percent:

  Percent waiting \> 18 weeks

## Source

<https://www.opendata.nhs.scot/>
