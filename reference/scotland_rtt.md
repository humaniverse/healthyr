# Consultant-led Referral to Treatment (RTT) in Scotland

A dataset containing RTT data for Scotland.

## Usage

``` r
scotland_rtt
```

## Format

A data frame with 153 rows and 5 variables:

- date:

  Date

- year:

  Year

- month:

  Month

- waits_over_18_weeks_count:

  Total number waiting \> 18 weeks

- waits_over_18_weeks_percent:

  Percent waiting \> 18 weeks

## Source

<https://www.opendata.nhs.scot/>
