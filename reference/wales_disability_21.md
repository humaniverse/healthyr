# Disability by LTLA for Wales, 2021

A dataset containing LTLA data on numbers disabled under the Equality
Act.

## Usage

``` r
wales_disability_21
```

## Format

A data frame:

- ltla21_code:

  LTLA code

- total_residents:

  Total residents in the local authority

- disability_level:

  Disabled or Not disabled under the Equality Act

- n:

  number of people

- prop:

  proportion of people
