# Wales health board bed availability - (2022 - )

A dataset containing Welsh monthly NHS beds data by health board,
measure, and specialty

## Usage

``` r
wales_health_board_critical_general_acute_beds
```

## Format

A data frame with 1,595 rows and 7 variables:

- date:

  Date

- health_board_code:

  Local health board code

- health_board_name:

  Name of local health board

- specialism:

  Name of specialism

- daily_beds_available:

  Average number of daily beds available

- daily_beds_occupied:

  Average number of daily beds occucpied

- beds_occupancy_rate:

  Bed occupancy rate

## Source

<https://statswales.gov.wales/>
