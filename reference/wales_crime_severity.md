# Crime severity score in Wales

Crime severity score is based on sentencing data, community order and
fines. Higher scores mean greater severity within an area.

## Usage

``` r
wales_crime_severity
```

## Format

A data frame containing 2 columns.

- ltla23_code:

  Local Authority code

- crime_severity_score:

  Crime severity score (higher = more severe)

## Source

<https://www.ons.gov.uk/peoplepopulationandcommunity/crimeandjustice/datasets/crimeseverityscoreexperimentalstatistics>
