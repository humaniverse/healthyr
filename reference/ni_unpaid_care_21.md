# Provision of unpaid care (delayed discharge) in Northern Ireland

A dataset containing unpaid care data in Local Government Districts in
NI from 2021 census.

## Usage

``` r
ni_unpaid_care_21
```

## Format

A data frame with 605 rows and 4 variables:

- ltla21_name:

  Local Government Districts name

- ltla21_code:

  Local Government Districts code

- variable:

  Age band and count/percentage of unpaid care hours

- value:

  Value of the chosen variable

## Source

<https://www.nisra.gov.uk/>
