# Scotland A&E attendances

A dataset of hospital-level A&E attendances and waiting times for
Scotland (from 2007-07 to 2025-02).

## Usage

``` r
scotland_ae_attendance
```

## Format

A data frame with 17,844 rows and 6 variables:

- hospital_code:

  Hospital code

- hospital_name:

  Hospital name

- date:

  Date

- attendances:

  Number of total attendances

- within_4_hours:

  Number of attendances lasting less than 4 hours

- over_4_hours:

  Number of attendances lasting more than 4 hours
