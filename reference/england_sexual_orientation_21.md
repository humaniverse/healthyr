# Sexual orientation, England, 2021

A dataset containing sexual orientation data at LTLA level

## Usage

``` r
england_sexual_orientation_21
```

## Format

A data frame with 1,655 rows and 5 variables:

- ltla21_code:

  LTLA code

- total_residents:

  Residents in the LTLA

- sexual_orientation:

  Sexual orientation

- n:

  Number of people

- prop:

  Percentage
