# Consultant-led Referral to Treatment (RTT) pathway flow by ICS/STP

A dataset containing ICS/STP-level RTT data spanning from Apr 2020 to
Feb 2025.

## Usage

``` r
england_rtt_flow_stp
```

## Format

A data frame with 2,478 rows and 7 variables:

- stp20_nhs_code:

  NHS code for the ICS/STP

- date:

  Date

- year:

  Year

- month:

  Month

- completed:

  Number of pathways completed

- incomplete:

  Number of incomplete pathways

- new:

  Number of new pathways

## Source

<https://www.england.nhs.uk/>
