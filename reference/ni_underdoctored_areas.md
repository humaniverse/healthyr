# Underdoctored areas in Northern Ireland

A dataset containing the ratio of patients to GP workforce, by Local
Authority

## Usage

``` r
ni_underdoctored_areas
```

## Format

A data frame with 6 variables:

- ltla21_code:

  Local Authority code (2021)

- ltla21_name:

  Local Authority name (2021)

- date:

  year

- total_patients:

  Number of registered patients

- total_gp:

  Number of GPs

- patients_per_gp:

  Number of patients per GP
