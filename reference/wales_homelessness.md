# Homelessness in Wales

A dataset containing statistics on households assessed as homeless and
households in temporary accommodation, by Local Authority.

## Usage

``` r
wales_homelessness
```

## Format

A data frame with 3 variables:

- ltla21_code:

  Local Authority code

- `Homeless or threatened with homelessness per 1,000`:

  Households assessed as homeless per 1k households in the Local
  Authority

- `Households in temporary accommodation per 1,000`:

  Households in temporary accommodation per 1k households in the Local
  Authority

## Source

<https://statswales.gov.wales/>
