# Disability by LTLA for England, 2021

A dataset containing LTLA data on numbers disabled under the Equality
Act.

## Usage

``` r
england_disability_21
```

## Format

A data frame with 662 rows and 5 variables:

- ltla21_code:

  LTLA code

- total_residents:

  Total residents in the local authority

- disability_level:

  Disabled or Not disabled under the Equality Act

- n:

  number of people

- prop:

  proportion of people
