# England Health Index (ONS)

A dataset containing overall health index scores for the English
Integrated Care Boards from 2015-2021.

## Usage

``` r
england_health_index_ics
```

## Format

A data frame with 294 rows and 7 variables:

- icb22_code:

  2022 Integrated Care Board code

- icb22_name:

  2022 Integrated Care Board name

- year:

  Year

- overall_score:

  The overall health index score

- healthy_people_domain_score:

  Score for the Healthy People domain

- healthy_lives_domain_score:

  Score for the Healthy Lives domain

- healthy_places_domain_score:

  Score for the Healthy Places domain

## Source

<https://www.ons.gov.uk/>
