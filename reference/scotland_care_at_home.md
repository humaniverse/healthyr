# Care at Home in Scotland

Scotland Health-Board level data for the number of people (per 1,000
population) supported by care at home (from 2018-Q1 to 2024-Q1).

## Usage

``` r
scotland_care_at_home
```

## Format

A data frame containing 800 rows and 4 columns.

- ltla24_code:

  2024 Lower tier local authority code

- ltla24_name:

  2024 Lower tier local authority name

- date:

  Date

- care_at_home_per_1000:

  Number of people (per 1,000 population) receiving care at home
