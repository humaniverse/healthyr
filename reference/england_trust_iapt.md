# Physchological Therpaies - IAPT

A dataset containing NHS Trust level IAPT data.

## Usage

``` r
england_trust_iapt
```

## Format

A data frame with 5,082 rows and 4 variables:

- nhs_trust22_code:

  NHS Trust (organisational) code

- date:

  Date

- name:

  Name of the variable

- value:

  Value of the variable

## Source

<https://www.england.nhs.uk/>
