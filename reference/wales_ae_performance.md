# Emergency department performance statistics

A dataset containing performance against waiting times targets by
hospital.

## Usage

``` r
wales_ae_performance
```

## Format

A data frame with 73,863 rows and 5 variables:

- hospital_code:

  Hospital code

- hospital_department:

  Hospital or department name

- date:

  Date

- performance_measure:

  Performance measure

- performance_target:

  Performance target

- data:

  Data

<https://statswales.gov.wales/>
