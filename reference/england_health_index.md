# England Health Index (ONS)

A dataset containing overall health index scores for the English lower
tier local authorities from 2015-2021.

## Usage

``` r
england_health_index
```

## Format

A data frame with 2,149 rows and 6 variables:

- ltla21_code:

  2021 Lower tier local authority code

- year:

  Year

- overall_score:

  The overall health index score

- healthy_people_domain_score:

  Score for the Healthy People domain

- healthy_lives_domain_score:

  Score for the Healthy Lives domain

- healthy_places_domain_score:

  Score for the Healthy Places domain

## Source

<https://www.ons.gov.uk/>
