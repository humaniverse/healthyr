# Underdoctored areas in Wales

A dataset containing the ratio of patients to GP workforce, by Local
Authority

## Usage

``` r
wales_underdoctored_areas
```

## Format

A data frame with 4 variables:

- ltla24_code:

  Local Authority code (2024)

- total_patients:

  Number of registered patients

- total_gp:

  Number of GPs

- patients_per_gp:

  Number of patients per GP
