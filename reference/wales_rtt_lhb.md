# Consultant-led Referral to Treatment (RTT) by Local Health Board

A dataset containing RTT data for Wales.

## Usage

``` r
wales_rtt_lhb
```

## Format

A data frame with 2,212 rows and 7 variables:

- lhb22_code:

  Local Health Board code

- lhb22_name:

  Local Health Board name

- date:

  Date

- pathway_stage:

  Stage of the treatment pathway

- waits_over_18_weeks:

  Total waiting \> 18 weeks

- waits_over_53_weeks:

  Total waiting \> 53 weeks

- total_waits:

  Total waiting
