# Scotland A&E Admission Outcomes

A dataset containing Scotland hospital-level admission outcomes
stratified by age group (from 2018-01 to 2025-02)

## Usage

``` r
scotland_ae_admission
```

## Format

A data frame with 86,688 rows and 6 variables:

- hospital_code:

  Hospital code

- hospital_name:

  Hospital name

- date:

  Date

- admission:

  Admission outcome

- age:

  Age group

- attendances:

  Total number of attendances falling into each category
