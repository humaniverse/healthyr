# Legal Partnership Status, Wales, 2021

A dataset containing legal partnership status data at LTLA level

## Usage

``` r
wales_legal_partnership_21
```

## Format

A data frame:

- ltla21_code:

  LTLA code

- total_population:

  Population in the LTLA

- legal_partnership:

  Type of legal partnership

- n:

  Number of people

- prop:

  Percentage
