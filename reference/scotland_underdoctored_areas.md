# Underdoctored areas in Scotland

A dataset containing the ratio of patients to GP workforce, by Local
Authority

## Usage

``` r
scotland_underdoctored_areas
```

## Format

A data frame with 4 variables:

- ltla21_code:

  Local Authority code (2021)

- total_gp:

  Number of full-time equivalent GPs

- total_patients:

  Number of registered patients

- patients_per_gp:

  Number of patients per GP
