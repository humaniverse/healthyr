# Statutory homelessness in England

A dataset containing statistics on households assessed as homeless and
households in temporary accommodation, by Local Authority.

## Usage

``` r
england_homelessness
```

## Format

A data frame with 3 variables:

- ltla23_code:

  Local Authority code

- `Households assessed as homeless per (000s)`:

  Households assessed as homeless per 1,000 households in the Local
  Authority

- `Households in temporary accommodation per 1,000`:

  Households in temporary accommodation per 1,000 households in the
  Local Authority

## Source

<https://www.gov.uk/government/statistical-data-sets/live-tables-on-homelessness>
