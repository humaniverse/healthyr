# Hospital ICB Discharge Data - Criteria to Reside

A dataset containing NHS Integrated Care Board discharge data on how
many patients do not meet criteria to reside each day.

## Usage

``` r
england_icb_criteria_to_reside
```

## Format

A data frame with 51,727 rows and 3 variables:

- icb22_code:

  Integrated Care Board code

- date:

  Date

- do_not_meet_criteria_to_reside:

  Number of patients who no longer meet the criteria to reside

## Source

<https://www.england.nhs.uk/>
