# Consultant-led Referral to Treatment (RTT) by ICS/STP

A dataset containing ICS/STP-level RTT data spanning from Apr 2020 to
Feb 2025.

## Usage

``` r
england_rtt_stp
```

## Format

A data frame with 55,73 rows and 7 variables:

- stp20_nhs_code:

  NHS code for the ICS/STP

- stp20_name:

  Name of the ICS/STP

- date:

  Date

- year:

  Year

- month:

  Month

- treatment:

  Treatment function name

- waits_over_18_weeks:

  Total waiting \> 18 weeks

- waits_over_52_weeks:

  Total waiting \> 52 weeks
