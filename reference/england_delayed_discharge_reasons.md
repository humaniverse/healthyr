# Disability by LTLA for England, 2021

A dataset containing LTLA data on numbers disabled under the Equality
Act.

## Usage

``` r
england_delayed_discharge_reasons
```

## Format

A data frame with 45,106 rows and 5 variables:

- nhs_trust22_name:

  NHS Trust name

- nhs_trust22_code:

  NHS Trust code

- date:

  Date in the format year-month-day

- delay_reason:

  The reason for the delayed discharge

- delay_count:

  The number of delays

## Source

<https://www.england.nhs.uk/statistics/statistical-work-areas/discharge-delays/acute-discharge-situation-report/>
